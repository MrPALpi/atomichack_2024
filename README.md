# `Классные перчики` и проект для *Атомик Хак 2.0*

## Тизер проекта
Проект состоит из 3 Docker контейнеров: 
- ML модель (Yolo 10)
- web backend с API для работы с моделью
- web frontend для работы с модлеью конечным пользователям

Пользователи авторизируются через веб-приложения и загружают фотографии или архив фотографий. Далее нейросеть определяет и классифицирует дефекты и возращает результат на страницу результатов. Пользователи могут ознакомиться с дефектами на этой странице.

## Развертывание проекта
`cp .env.example .env` + настроить перменные
`docker compose up -d`

## Настройка сервиса vue
Установка зависимостей npm: `npm i`  
Запуск сервиса: `npm run build && npm run preview`
Запуск сервиса для *dev* режима `npm run dev`

## Настройка сервиса fast-api
Требования:
 - poetry
Установка зависимостей Python: `poetry install`  
Запуск сервиса: `poerty run start-app`
